What’s new in 1.3.0 · 2026-10-10

One table across pages

When a table continues on the next page, PDFTrail joins the pieces into one table in Excel, Word and Markdown. A row cut by the page break becomes one row again.

Table Review · grid editor

After a conversion, Table Review shows each table found. If a table is wrong, drag its grid lines into place, then accept it. Or open the file as it is.

Cleaner scan text

PDFTrail keeps far more of the words on a scanned page and drops repeated ones. Tables on clean scans keep their rows, columns and cell text.

Three themes

Choose Blueprint, Terminal or Field Unit. Change the look at any time in the sidebar.
